# ماه‌گل 🌙

وب‌اپ فارسی تقویم چرخه با نصب روی صفحهٔ اصلی گوشی. تمام فایل‌های لازم برای GitHub Pages در همین پوشه هستند. نصب نرم‌افزار روی کامپیوتر یا اجرای دستور لازم نیست.

## انتشار در گیت‌هاب

1. فایل ZIP را از حالت فشرده خارج کن تا فایل‌هایی مثل `index.html` و `sw.js` را ببینی.
2. وارد حساب گیت‌هابت شو و [یک مخزن تازه بساز](https://github.com/new). اسم پیشنهادی `mahgol` است. برای حساب رایگان **Public** را انتخاب کن. **Add a README file** را روشن کن و **Create repository** را بزن.
3. در صفحهٔ **Code** مخزن، **Add file → Upload files** را بزن. همهٔ فایل‌های داخل پوشهٔ استخراج‌شده را با هم انتخاب کن و **Commit changes** را بزن. بالای صفحهٔ Code باید `index.html` را مستقیم در کنار `app.js` ببینی. اگر برای خود ZIP یا پوشهٔ بیرونی یک ردیف می‌بینی، فایل‌های داخل آن را هم در ریشهٔ مخزن آپلود کن.
4. وارد **Settings → Pages** شو. زیر **Build and deployment**، در **Source** گزینهٔ **Deploy from a branch**، در **Branch** شاخهٔ **main** و برای پوشه **/ (root)** را انتخاب کن. **Save** را بزن. اگر نام شاخهٔ پیش‌فرض حسابت فرق دارد، همان شاخه‌ای را انتخاب کن که فایل‌ها در آن هستند.
5. چند دقیقه بعد همین صفحه را تازه کن. با **Visit site** ماه‌گل را باز کن. همان لینک را بفرست. برای مخزن `mahgol` نشانی معمولاً به شکل `https://USERNAME.github.io/mahgol/` است. اگر ۴۰۴ دیدی، وضعیت انتشار را در **Actions** و جای `index.html` را در **Code** بررسی کن.

## روی گوشی

- **اندروید** — لینک را با Chrome باز کن، «نصب ماه‌گل» را بزن و نصب را تأیید کن. اگر پنجرهٔ نصب ظاهر نشد، در منوی سه‌نقطهٔ Chrome دنبال **Install app** یا **Add to Home screen** بگرد.
- **آیفون** — لینک را در Safari باز کن. **Share → Add to Home Screen → Add** را بزن. اگر **Open as Web App** را دیدی، روشنش کن.
- آیکن تاج صورتی ماه‌گل را از صفحهٔ اصلی باز کن. برای بار اول به اینترنت وصل باش. بعد از آماده شدن نسخهٔ آفلاین، تقویم، ثبت سابقه، دفتر و تمرین‌ها بدون اینترنت هم باز می‌شوند.
- برای شروع، «ثبت سابقهٔ پریود» را بزن و تاریخ شروع و پایان دو یا سه دورهٔ اخیر را از قدیم به جدید وارد کن. بهتر است اطلاعات را بعد از نصب از خود آیکن وارد کنی.

## یادآورها و حریم خصوصی

وقتی ماه‌گل بسته است، از «پیام‌های عاشقانه → دریافت فایل تقویم» یادآورها را به تقویم گوشی اضافه کن و اعلان تقویم را روشن کن. بعد از تغییر سابقهٔ چرخه، یادآورهای قدیمی را حذف و فایل تازه را وارد کن.

این بسته شامل کد برنامه و پیام‌های نمونه است. در مخزن عمومی، هر دو قابل مشاهده‌اند. متن‌های شخصی‌تر را می‌توان داخل خود برنامه و روی گوشی تغییر داد. سابقه و یادداشت‌هایی که در برنامه ثبت می‌شوند در مرورگر یا وب‌اپ همین دستگاه ذخیره می‌شوند و در مخزن گیت‌هاب قرار نمی‌گیرند. نسخه‌ای که روی نشانی دیگری استفاده می‌کردی دفتر جداگانه‌ای دارد. پاک کردن داده‌های برنامه یا مرورگر می‌تواند دفتر را پاک کند.
